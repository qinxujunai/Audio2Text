开始之前，了解这些。

需要什么电脑？

Windows 10 / 11，64 位。CPU 可完成本地识别；NVIDIA 显卡可使用可选 CUDA 组件。首次启动需要联网准备模型与运行组件，之后本地文件可离线识别。

为什么首次启动还要下载？

安装包包含基础应用，识别模型与媒体组件按需下载并核对校验值。CUDA 模型与组件独立准备，不会自动更改显卡驱动或系统环境。

哪些链接可以整理？

支持哔哩哔哩、小宇宙、抖音、小红书与微信公众号图文。能否读取也取决于网络、登录与平台访问规则；受限内容会提示恢复方式。平台支持不代表每条链接都能成功。

AI 校对能保证正确吗？

不能。模型只提出建议，你逐处确认后才能保存。数字与单位有额外保护，但人名、事实和语义仍需自己核对；原文与校对版始终分别保留。

摘要与要点如何生成？

在结果页手动生成，应用会先说明所用模型服务、发送范围和可能的费用。摘要附有原文依据，单独保存；AI 内容仍需对照原文核查。

Windows 为什么提示安全警告？

当前安装包尚未代码签名。请从本页的 GitHub Release 下载，并核对上方 SHA-256；遇到问题可通过页脚反馈入口提交。
