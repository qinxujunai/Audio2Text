本轮只调整小红书公开网页读取，不修改品牌、界面比例、转写模型、CUDA 设置或已有记录。

## 根因与实现

同一条用户提供的完整分享链接，在匿名桌面请求下返回登录空壳；手机网页请求返回真实正文和九张图片。旧解析器只识别 `note.noteDetailMap`，漏掉手机网页的 `noteData.data.noteData`。

- 兼容两种结构，复用已有图片、视频和 Live Photo 规范化逻辑；手机数据必须包含笔记身份和内容，空壳不算成功。
- `/discovery/item/` 分享先读取手机网页，其他地址先读取桌面网页；成功即停，无数据时仅换一次浏览器标识。完整分享参数保持不变，不新增 Cookie、登录或网络配置。
- 读取按块检查时间预算并限制页面为 8 MiB，防止持续小块响应无限延长等待。单次阻塞仍由 HTTP 客户端的 I/O 超时控制，这不是硬实时终止保证。HTTP 拒绝仍走原有结构化错误路径。
- 云端 relay 与浏览器恢复策略保持原样；本轮匿名手机请求的成功证据只适用于本机公开直连。

## 已验证的范围

项目级真实 API 完整 Capture 流程已通过：结果首次出现约 1.6–2.1 秒，九张图片全部本地就绪约 5.2–7.2 秒；正文下载、九张单图下载、九文件压缩包 CRC 检查通过。耗时是该链接的单次观测范围，不代表平台整体性能。

源描述为 146 字，包含话题标签。交付正文为 15 字，沿用现有社交内容清理规则移除话题标签；原始描述保留在来源元数据中。没有将正文长度变化误判为模型准确率或丢失解析数据。

合成回归覆盖桌面兼容、手机正文和媒体、错误数据结构、完整分享参数、备用次数、慢速分块、页面大小、TLS 默认验证及既有代理参数。原始分享签名、私人历史和服务日志不进入公开仓库。

本地详细证据位于 `tests_runtime/product-upgrade/xhs-mobile-20261021/`。源码、打包文件和已安装程序分别验收，不能把项目 API 成功当作安装版已更新。

## 发布边界

这条真实链接是定向兼容性回归，不替代五个平台至少 60 条独立链接、三轮及每平台每轮完整成功的发布门槛。旧六平台报告保留全部失败。最终安装来源、备份位置、原生窗口和 CUDA 复验记录以本轮本地交付报告为准；未通过全部门槛时不宣称正式 Release 或官网已更新。
