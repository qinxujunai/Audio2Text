## 确认代码所在位置

2.3 实现在 `codex/wanxiang-platform-audio-ui`（[PR #2](https://github.com/qinxujunai/Audio2Text/pull/2)）；默认分支文档快照不代表代码已经合并。先检查当前分支、文件、配置与运行进程，保留其他窗口的改动。没有依据时不重新安装、不改全局环境、不变更模型或视觉风格。

## 若用户明确要求恢复工作

- 优先读取既有证据，找出本次真正缺少的验证，只运行与变更风险相称的检查。
- 不固定宣称“122 个测试通过”，不为了全绿原样重复长测试，不把跳过或网络失败算成功。
- 不随意清理死代码或重构无关模块，不手工编辑构建产物。
- 平台支持当前为五个；不恢复 YouTube，不新增 VPN、Cookie 或登录配置。
- 修复后报告具体文件、原因、验证、剩余限制；缺人工参考不报告准确率，缺真实安装窗口不宣称安装体验通过。

## 若用户明确要求正式发布

先确认提取与准确率门槛均满足，再按 [部署说明](deployment.md)、[发布收口](release-ready.md) 和 `scripts/upgrade_local.ps1` 的协议交付。最终冻结、真实安装、数据保留、干净 Windows、同一文件公开上传及官网下载哈希必须形成闭环。网页上线或源码提交不等于新安装包发布。

当前已有提取超时与 npm 审计网络阻断，不能自行提高时限、删失败或跳过安全门槛。恢复条件未改变时，记录受阻状态并停止自动重跑。
