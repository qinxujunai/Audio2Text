---

## 提示词开始

继续 Audio2Text（万象成文）项目。你需要先读取 AGENTS.md 和 CLAUDE.md 了解项目规则和当前状态。

然后执行上线前最终闭环，按以下顺序逐步完成：

### 第一步：测试全绿

1. 运行后端测试：`python -m unittest discover -s tests -p "test_*.py"`，确认 122 个测试全部通过（1 个 skip 是正常的，那是需要线上配置的 smoke test）
2. 运行 TypeScript 类型检查：`cd web && npm exec tsc -- --noEmit`，确认零错误
3. 运行前端构建：`cd web && npm run build`，确认构建成功
4. 如果有测试失败，定位根因并修复，修复后重新跑测试直到全绿

### 第二步：功能冒烟测试（浏览器截图审核）

用 Playwright 打开本地服务（`http://localhost:8000`），逐页截图审核：

1. **首页**：截图确认输入框、提交按钮、品牌标识正常显示
2. **处理中页面**：提交一个 URL 后截图，确认进度条、状态文案正常
3. **结果页 — 图文链接**：提交一个小红书/微信公众号图文链接，截图确认：
   - hero 区：pill + 标题 + 副标题正常显示
   - 正文卡片：文字排版、行高、颜色正常
   - 图片网格：图片正常加载、可点击放大
   - meta footer：标题、平台、内容类型、查看来源标签齐全
4. **结果页 — 视频链接**：提交一个 YouTube/B站视频链接，截图确认：
   - hero 区正常
   - 视频预览区可播放
   - 正文（字幕/文稿）正常显示
   - meta footer 信息齐全
5. **图片查看器**：点击结果页图片，截图确认全屏查看层正常（模糊背景、关闭按钮、导航箭头）
6. **失败态**：故意提交一个无效链接，截图确认错误提示友好、不暴露技术细节
7. **移动端适配**：用 Playwright 设置 375px 宽度，截图确认响应式布局正常

每个截图都要用苹果 HIG 标准审核：间距是否为 8pt 倍数、触控目标是否 ≥ 44pt、字体层级是否清晰、有无视觉瑕疵。发现问题就修，修完重新截图确认。

### 第三步：代码与文档一致性

1. 检查 README.md 中的功能描述是否与实际代码一致
2. 检查 AGENTS.md 中的项目规则是否与当前代码状态一致
3. 检查 docs/ 目录下所有文档是否有过时引用（如已删除的 `result-mode-tabs`、`textViewMode`、`facts-strip`、`details row` 等）
4. 检查前端 CSS 类名是否都在 TSX 中有引用，TSX 中引用的类名是否都在 CSS 中定义
5. 不一致的地方修正后说明改了什么

### 第四步：死代码清理

1. 检查所有 .tsx 文件中是否有未使用的 import、未使用的变量、未使用的函数
2. 检查 styles.css 中是否有未被任何 TSX 引用的 CSS 选择器
3. 检查后端 Python 文件中是否有未使用的 import 或死函数
4. 确认 `frontend/dist/` 是构建产物，不需要手工编辑
5. 清理发现的死代码，说明删除了什么

### 第五步：中国平台访问验证

1. 确认 Cloudflare Worker 中继配置正确（检查 `scripts/cf_worker_proxy.js` 和环境变量）
2. 确认 `DEPLOYMENT_MODE` 在 cloud_preview 模式下会自动启用 relay
3. 确认本地模式（`DEPLOYMENT_MODE=local`）下走直连
4. 如果能测试，提交一个小红书或抖音链接验证中国平台可达

### 第六步：记录结论

在 AGENTS.md 的维护日志中新增一个条目，格式如下：

```
### YYYY-MM-DD 上线前最终闭环

**测试验证**
- 后端测试：X passed / Y skipped
- TypeScript：零错误
- 前端构建：成功

**功能冒烟**
- 首页 / 处理中 / 结果页（图文）/ 结果页（视频）/ 图片查看器 / 失败态 / 移动端
- 每项列出「通过」或「已修复：XXX」

**代码质量**
- 死代码清理：列出删除项（或「无」）
- 文档一致性：列出修正项（或「无」）

**结论**
- 是否可以上线：是/否
- 遗留风险：列出已知风险（如有）
```

### 第七步：最终构建确认

所有修改完成后，重新跑一遍完整验证：

1. `python -m unittest discover -s tests -p "test_*.py"`
2. `cd web && npm exec tsc -- --noEmit`
3. `cd web && npm run build`

全部通过后，提交代码并说明这是上线前最终闭环。

## 提示词结束

使用方法：复制「提示词开始」到「提示词结束」之间的全部内容，粘贴到新的 Claude Code 会话中执行。
