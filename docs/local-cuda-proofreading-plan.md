# 本地 CUDA 与保守校对

本批次由用户授权直接实施。另一窗口负责结果页布局；本批次复用其最终布局，不重新设计品牌或改动现有下载语义。

## 验收范围

1. 本机桌面转写默认 CUDA；中文平台也遵守设备选择。CUDA 模式不静默回退 CPU。状态显示区分已选择设备与最近实际运行设备。
2. 默认仍使用 SenseVoice Small 家族。CUDA 使用官方 sherpa-onnx CUDA SDK 和 FP32 通用权重，原 CPU int8 模型保留为兼容模式。Faster-Whisper 仅作为明确选择的备用模型；不移动已有模型，不修改全局环境。
3. 设置收纳设备和校对服务。填写兼容 API 地址与密钥后检测模型，支持手动模型名。Windows 密钥用当前用户 DPAPI 加密；不返回或记录明文密钥。
4. 校对由用户明确点击触发，文字发送至其配置服务。只提出小范围明确错字或标点修正，禁止总结、润色、删段、改数字和重排。
5. 原文永久保留；程序验证每处修改与原文精确对应，用户核对建议后保存独立校对版，两版可分别下载。长文分块，异步处理，可取消、显示进度和恢复已保存版本。
6. 新接口仅允许本地使用；复用桌面令牌边界，禁止公开部署访问。校对失败不得影响原始 Capture。

## 顺序与验证

- 先完成设备路由、模型加载与保守校对服务回归测试。
- 再接独立设置/校对组件；等待另一窗口布局完成后加小入口。
- 检查模型列表认证失败、校对非法改动/删段/数字变化、原文哈希变化、重复任务、取消、秘钥不回传。
- 执行后端测试、类型检查、前端构建、桌面与窄屏浏览器检查。
- 使用刚完成的本地媒体片段执行真实 CUDA 推理，记录实际设备、耗时和模型；单独报告是否替换已安装程序及回滚位置。

## 当前证据

2026-10-11 决策修正：CUDA 可运行不代表 Whisper medium 优于 SenseVoice Small。两者模型不同、设备不同的速度记录不能用来计算 CUDA 的加速收益。当前不得据此替换安装版的默认模型；模型决策需要中文 CER、英文 WER、中英混说 MER 和同条件运行数据，公开评测与本机实测必须分开。详见 `asr-model-quantitative-audit-20261011.md`。

用户这次哔哩哔哩任务长 15427 秒，提取 778.271 秒，CPU SenseVoice 转写 826.687 秒。当前电脑为 RTX 3060 Laptop 6GB；项目 CTranslate2 检测到一个 CUDA 设备。以上不能证明更换模型后的准确率或整段速度，必须实测。

2026-10-11 已完成 CUDA 验证：3 分钟用户音频，同一 FP32 `model.onnx`、相同分块、batch=1、各三轮，CPU 中位数 12.346 秒，CUDA 1.135 秒，10.873 倍；两端文字完全相同。CUDA batch=4 中位数 0.869 秒。四小时原音频完整解码及 CUDA 识别 107.260 秒，643 段，音轨结束 15426.247 秒。报告：`workspace/benchmarks/sensevoice-same-model-cuda-20261011.json`。

必须区分版本：原安装版 int8 元数据为 `ASLP-lab/WSYue-ASR`（粤语微调），新 CUDA 权重为 `FunAudioLLM/SenseVoiceSmall`（通用版）。四小时 826.687→107.260 秒是完整识别链路的实测对照，不能当作同一权重的纯 CUDA 倍率；10.873 倍才是同权重、同批量对照。未获得四小时人工参考，因此不声明整体准确率提升。

CUDA 模型与 SDK 在独立进程加载，避免与 CPU 后端的 ONNX DLL 冲突；模型驻留，启动后后台预热，分块解码只缓存约 29 秒 PCM，每批最多四段。安装包复用后端可执行程序作为 worker，不内置 GPU 驱动或模型。`scripts.prepare_sensevoice_cuda` 固定来源 revision 并校验 SHA-256，可断点续传，未改动项目 venv。
