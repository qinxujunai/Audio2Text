# 2.3 候选独立审查与修正

独立只读审查发现并复现三项问题：提取验收信任摘要、sidecar 只绑定 exe、取消未绑定 job_id。修正后 44 项针对性测试、339 项后端测试（1 项外网 smoke 跳过）与 5 项真实浏览器交互回归通过，TypeScript 与 Vite 构建通过。

- 提取成功、完整、失败、超时率从原始记录计算；矛盾摘要拒绝。风控计入失败。每个平台每轮至少有一个完整成功样本才满足可用性门槛；这不是 100% 成功率承诺。
- sidecar 完整资源树用相对路径与 SHA-256 绑定；跳过重建、打包结束、打包验收前后与安装前校验。单个 DLL 变更、增添或删除都使原验收无效。
- 取消请求携带 job_id；旧任务不能取消新任务，完成的任务不会被迟到取消改写状态，同任务重复取消保持幂等。

当前修正属于源码，尚未进入本机已安装候选。已安装候选仍是 SHA-256 为 `d3df68fddb8054c99e9262f3674a41e04c630abb3a95398b9ee51f89e634fe56` 的保存文件。最终包必须重新构建、验收、备份安装再验证。
